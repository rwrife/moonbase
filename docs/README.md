# Selene Frontier planning hub

**Selene Frontier** is a working title for an original, single-player lunar
colony strategy game inspired by the engineering/economy of the 1990 *Moonbase*.
The goal is an isometric 3D Godot game with deep strategy and a long-term
high-fidelity visual target.

- [Proposed Godot architecture and implementation guide](ARCHITECTURE.md)
- [Phased roadmap with 15 actionable developer issues](ROADMAP.md)
- [Art direction and current desktop/Web constraints](ART_AND_PLATFORMS.md)
- [Historical references, uncertainty and ownership policy](SOURCES.md)

## What is not implemented

There is **no runnable Godot project or playable build yet**. Downloading and
executing the engine, writing game project files, changing generated-file
ignores, and deleting/replacing the existing root README were denied in the
initial environment. The original root README remains untouched. The permitted
deliverables are these documents and the published GitHub issues.

The foundation and validation issues cover the remaining project setup and
first playable. Native-mobile feasibility issue creation was separately denied
as outside the authorized scope; mobile is not part of the published backlog.
No engine, export, gameplay, visual-quality, or performance validation has run.

The owner requested direct publication to `main` for this initial setup. This
does not establish an unconditional direct-to-main policy for future developers.
