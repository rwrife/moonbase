# Selene Frontier planning hub

**Selene Frontier** is a working title for an original, single-player lunar
colony strategy game inspired by the engineering/economy of the 1990 *Moonbase*.
The goal is an isometric 3D Godot game with deep strategy and a long-term
high-fidelity visual target.

## Delivered in this setup

- [Project description and complete system design](DESIGN.md)
- [Godot architecture and implementation guide](ARCHITECTURE.md)
- [Phased roadmap with 15 actionable developer issues](ROADMAP.md)
- [Art direction and current desktop/Web constraints](ART_AND_PLATFORMS.md)
- [Historical references, uncertainty and ownership policy](SOURCES.md)

The approved continuation also adds a runnable Godot 4.7.2 project, original
procedural isometric 3D scene, eight building types, utility/economy simulation,
HUD, camera controls, founding scenario, Linux/Web export presets, behavioral
tests, CI and contributor/issue templates. See [the root README](../README.md)
for run commands and controls.

## Remaining scope

AAA production assets, research trees, saves, detailed crew/logistics, additional
hazards, campaign, and audio remain future issue work. The initial permission
block on game-file writes and Godot execution was resolved by explicit owner
approval. Native-mobile feasibility was separately denied and is not part of
the published backlog or supported platforms.

The owner requested direct publication to `main` for this initial setup. This
does not establish an unconditional direct-to-main policy for future developers.
